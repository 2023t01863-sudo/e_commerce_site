# Oceanic Treasures - E-Commerce Platform

A modern, scalable MERN-stack e-commerce platform designed for a specialized business selling sea ornaments, pearls, and ocean-themed jewelry.

## 📌 Project Overview
This is a Single-Vendor E-Commerce system built to provide a seamless shopping experience for high-value, delicate items. The platform includes a responsive web application, a cross-platform mobile app, and a powerful admin dashboard for inventory management.

## 🛠️ Tech Stack
This project is built using the **MERN Stack**:
*   **Frontend (Web):** React.js & Next.js (SEO optimized)
*   **Backend:** Node.js & Express.js
*   **Database:** MongoDB (NoSQL for flexible product attributes)
*   **Mobile App:** Flutter & Dart
*   **Tools:** Git, Postman, Docker

## ✨ Key Features
### Customer-Facing:
*   High-Resolution Image Gallery (Zoom-in for details)
*   Advanced Product Filtering (Material, Type, Price)
*   Shopping Cart & Secure Checkout
*   Fragile Shipping Calculator

### Admin Dashboard:
*   Inventory Management (Auto-sold-out alerts for unique items)
*   Order Tracking & Status Updates
*   Sales Analytics
